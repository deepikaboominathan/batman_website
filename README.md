# The Dark Knight & The Magic of Maikey

Run: `npm install` then `npm run dev` -> http://localhost:3000

## Customize (all in `src/config/site.ts`)
- Photos: copy files into `public/images/memories/`, set `image: "/images/memories/1.jpg"`.
- Videos: copy into `public/videos/`, set `video: "/videos/clip.mp4"` (use .mp4 H.264; keep files small for WhatsApp/mobile).
- Music: paste Spotify/YouTube URLs in `songs` (opens in a new tab; nothing autoplays).
- Birthday wish: edit `birthdayWish`. Apology letter: edit `letter` (replace the [EDIT] line with your own words).

## Deploy
Push to GitHub, import on vercel.com (free), deploy. Share the link on WhatsApp.
